# NeverSoft plugin catalog

NeverSoft discovers compatible plugin APKs installed on the same Android device.

## Install

1. Install a NeverSoft-compatible plugin APK.
2. Open **Plugins** in NeverSoft.
3. Tap **Rescan for plugins**.
4. Review the tools exposed by the plugin before allowing the local agent to use them.

The catalog is repository-backed. Compatible plugin APKs and their checksums should be published under this repository's Releases. If no plugin assets are listed in the latest release, no public plugin pack is currently available; the Rescan action still detects compatible APKs already installed on the device.

[Open NeverSoft-CMD releases](https://github.com/ether4o4/NeverSoft-CMD/releases)
